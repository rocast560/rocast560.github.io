# Example / demo posts

Every `YYYY-MM-DD-*.md` file in this folder is **demo data**. It shows up on the
site while you develop locally (`jekyll serve`) and is automatically left out of
the published site.

- Add throwaway posts here to test formatting, categories, and tags.
- Move a file up into `_posts/` when you want to publish it for real.
- Full details and the on/off flag: see `README.md` in the project root.

(This README isn't a post, so Jekyll ignores it.)
